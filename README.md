# Blackjack Game

A simple browser-based **Blackjack game** built with **HTML, CSS, and JavaScript** while learning web development through **freeCodeCamp**.

## About the Project

This project was created as a learning exercise to practice the fundamentals of JavaScript and interactive web development.

It focuses on building a small game from scratch using basic front-end technologies without any frameworks or libraries.

## Features

* Start a Blackjack game
* Draw new cards
* Calculate the player's score
* Display game messages and results
* Basic Blackjack game logic
* Interactive buttons and gameplay
* Simple responsive interface

## Technologies Used

* **HTML5** — Structure of the game
* **CSS3** — Styling and layout
* **JavaScript** — Game logic, card handling, and score calculation

## How to Play

1. Open the game in your browser.
2. Click **START GAME** to begin.
3. Draw cards and try to get as close to **21** as possible.
4. Avoid going over 21.
5. Follow the game messages to see whether you win or lose.

## Getting Started

No installation or backend is required.

Clone the repository:

```bash
git clone https://github.com/nandlalgupta1809-dot/Black-Jack.git
```

Then open the project's main HTML file in a web browser.

You can also use **VS Code Live Server** for local development.
